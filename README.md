# learnweb

Личная учебная платформа по веб-разработке: JavaScript, PHP (8 и легаси 7.0), вёрстка, базы данных.
Написана на чистом PHP и JS без фреймворков — её код сам является учебным материалом.

## Запуск

Нужен только Docker.

```bash
docker compose up
```

Открой <http://localhost:8000>. Остановить: `Ctrl+C` или `docker compose down`.

Без Docker платформа тоже запускается, если установлен PHP 8.1+ с расширением `pdo_sqlite`:

```bash
php -S localhost:8000 -t public public/index.php
```

В этом режиме недоступен только запуск кода на PHP 7.

## Что внутри

| Путь | Что там |
|---|---|
| `content/course.php` | Программа курса: блоки и порядок уроков |
| `content/<блок>/<урок>/lesson.md` | Теория урока в Markdown |
| `content/<блок>/<урок>/tasks.php` | Задания и карточки для повторения |
| `public/index.php` | Точка входа: маршруты приложения |
| `src/` | Движок: роутер, Markdown, прогресс, запуск PHP-кода |
| `templates/` | HTML-шаблоны страниц |
| `public/assets/` | Стили и клиентский JS (редактор, проверка заданий) |
| `runner/` | Запуск PHP-кода в отдельном процессе; работает и на PHP 7.0 |
| `data/` | Твой прогресс (SQLite). В git не попадает |
| `tools/verify.js` | Проверка, что решения всех JS-заданий проходят тесты |
| `tools/verify-html.js` | То же для заданий по вёрстке — в настоящем браузере, нужен Playwright и запущенная платформа |

## Как устроена проверка заданий

- **JavaScript** выполняется в браузере, в отдельном потоке (Web Worker). Зависший код останавливается через 3 секунды.
- **Вёрстка** (HTML, CSS, Bootstrap) показывается в изолированной рамке `<iframe sandbox>`. Тесты выполняются внутри неё и проверяют разметку и вычисленные стили на разных ширинах окна. Так же устроены задания по JavaScript в браузере: тесты нажимают кнопки, вводят текст и отправляют формы, а ошибки скрипта и `console.log` видны в панели «Консоль» под предпросмотром.
- **PHP** выполняется на сервере платформы в отдельном процессе с ограничением 5 секунд. PHP 7.0 — в соседнем контейнере `php7`.

Платформа выполняет произвольный код, поэтому она слушает только `localhost`, а каждый запрос к API защищён токеном. Не открывай её порт во внешнюю сеть.

## Сбросить прогресс

Удали папку `data/` — она создастся заново.

## Сторонний код

Редактор — [CodeMirror 5](https://codemirror.net/5/) (лицензия MIT), лежит в `public/vendor/codemirror`.
[Bootstrap 5.3](https://getbootstrap.com/) (лицензия MIT) лежит в `public/vendor/bootstrap` и подключается только к предпросмотру заданий по Bootstrap.
