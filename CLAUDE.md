# learnweb

Личная учебная платформа по веб-разработке на чистом PHP и JS, без фреймворков. Интерфейс и содержимое — на русском.

**Перед любой работой прочитай `docs/ROADMAP.md`**: там договорённости с автором курса, формат уроков и заданий, API тестов, план оставшихся блоков и нужные доработки движка.

## Команды

```bash
docker compose up                                   # платформа + PHP 7.0, http://localhost:8000
php -S 127.0.0.1:8000 -t public public/index.php    # без Docker (PHP 7 недоступен)
node tools/verify.js                                # проверка JS-заданий
node tools/verify-html.js                           # проверка заданий с предпросмотром; нужен запущенный сервер
```

Оба скрипта проверки должны проходить перед каждым коммитом с содержимым.

## Правила

- Новый урок — папка `content/<блок>/<урок>/` с `lesson.md` и `tasks.php`, плюс имя в `content/course.php`.
- У каждого задания с кодом эталонное решение проходит тесты, а заготовка — нет.
- `runner/lib.php` и `runner/server.php` выполняются на PHP 7.0: только синтаксис 7.0.
- Папка `data/` — прогресс ученика, в git не попадает. После своих проверок удаляй её.
- Движок без зависимостей: Composer и npm-пакеты не добавлять. Сторонний код — только в `public/vendor`.
