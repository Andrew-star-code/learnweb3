# Bootstrap: сетка и утилиты

Bootstrap — это готовый файл CSS (и немного JavaScript) с набором классов. Вместо того чтобы писать стили, ты навешиваешь классы на элементы. Он стоит на огромном числе админок, внутренних систем и легаси-проектов, поэтому уметь его читать и писать нужно в любом случае.

Важно: в Bootstrap нет магии. Всё, что он делает, ты уже умеешь — это flexbox, медиазапросы и переменные из прошлых уроков, только записанные заранее.

## Подключение

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">
```

В заданиях этого блока Bootstrap 5.3 уже подключён к предпросмотру.

## Сетка: контейнер, ряд, колонки

```html
<div class="container">
  <div class="row">
    <div class="col-md-4">Боковая панель</div>
    <div class="col-md-8">Содержимое</div>
  </div>
</div>
```

Три уровня, и порядок вложенности обязателен:

- **`.container`** — центральная колонка с ограничением ширины. `.container-fluid` — на всю ширину окна.
- **`.row`** — ряд. Внутри это `display: flex; flex-wrap: wrap`.
- **`.col-*`** — колонки, прямые потомки ряда.

Ряд делится на **12 частей**. Число в классе — сколько частей занимает колонка: `col-6` — половина, `col-4` — треть, `col-3` — четверть. Если сумма в ряду больше 12, лишние колонки переносятся на следующую строку.

## Контрольные точки

Средняя часть класса — с какой ширины он начинает действовать.

| Класс | Действует от | Ниже этой ширины |
|---|---|---|
| `col-6` | Всегда | — |
| `col-sm-6` | 576px | Колонка на всю ширину |
| `col-md-6` | 768px | Колонка на всю ширину |
| `col-lg-6` | 992px | Колонка на всю ширину |
| `col-xl-6` | 1200px | Колонка на всю ширину |

Это «mobile first» в чистом виде: `col-md-6` означает «от 768px — половина, уже — на всю ширину». Классы комбинируются:

```html
<div class="col-12 col-sm-6 col-lg-3">…</div>
```

На телефоне — один столбец, от 576px — два, от 992px — четыре. Ровно то, что ты писал руками в прошлом уроке.

Просто `col` без числа — «раздели место поровну», как `flex: 1`.

Промежутки между колонками задаются на ряду: `g-0` … `g-5` (например, `row g-3`).

## Как это устроено внутри

Упрощённо, в исходниках Bootstrap написано следующее:

```css
.row { display: flex; flex-wrap: wrap; }

.col-6 { flex: 0 0 auto; width: 50%; }

@media (min-width: 768px) {
  .col-md-4 { flex: 0 0 auto; width: 33.3333%; }
  .col-md-8 { flex: 0 0 auto; width: 66.6667%; }
}
```

Промежутки сделаны внутренними отступами колонок и отрицательными внешними отступами ряда — поэтому колонки нельзя класть мимо `.row`, а `.row` мимо `.container`: без компенсации появится горизонтальная прокрутка.

## Утилиты

Утилита — класс, который делает одну вещь. Ими собирают оформление, не открывая CSS.

| Группа | Классы | Что делают |
|---|---|---|
| Отступы | `m-3`, `mt-2`, `mb-4`, `mx-auto`, `p-3`, `py-2`, `px-4` | `m` — margin, `p` — padding; `t b s e` — сверху, снизу, в начале, в конце; `x y` — по оси; число 0–5 |
| Flex | `d-flex`, `justify-content-between`, `align-items-center`, `gap-3`, `flex-column` | Свойства flexbox |
| Видимость | `d-none`, `d-block`, `d-md-block`, `d-md-none` | `display`, в том числе по контрольным точкам |
| Текст | `text-center`, `text-end`, `fw-bold`, `fs-4`, `text-muted` | Выравнивание, жирность, размер |
| Цвет | `text-primary`, `bg-light`, `bg-success`, `text-white` | Цвета темы |
| Оформление | `rounded`, `border`, `shadow-sm`, `w-100` | Скругление, рамка, тень, ширина |

Шкала отступов: `1` — 4px, `2` — 8px, `3` — 16px, `4` — 24px, `5` — 48px.

В Bootstrap 5 «лево» и «право» называются `s` (start) и `e` (end): `ms-2`, `pe-3`, `text-end`. В Bootstrap 4 были `ml-2`, `pr-3`, `text-right` — это первое, по чему отличают версии в старом коде.

Показать элемент только от планшета и шире: `d-none d-md-block` — «по умолчанию скрыт, от 768px виден».

## Когда Bootstrap уместен

- Админки и внутренние инструменты, где важна скорость, а не уникальный вид.
- Прототипы.
- Проекты, где он уже стоит.

Обратная сторона: разметка обрастает длинными списками классов, а сайты выглядят похоже друг на друга. Поэтому важно, что ты можешь сделать то же самое и без него.
