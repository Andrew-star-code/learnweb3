# Семантика HTML

HTML отвечает на вопрос «что это»: заголовок, абзац, список, кнопка, навигация. Как это выглядит — дело CSS. Тег, выбранный по смыслу, называют семантическим.

Страницу, свёрстанную одними `<div>`, браузер покажет точно так же. Но смысл тегов читают не только глаза:

- **программы экранного доступа** — по ним незрячий человек переходит от заголовка к заголовку и находит навигацию;
- **поисковые системы** — заголовкам и основному содержимому они доверяют больше;
- **сам браузер** — на `<button>` можно нажать с клавиатуры, а на `<div>` нельзя;
- **следующий разработчик** — `<nav>` понятнее, чем `<div class="top-block-2">`.

## Каркас страницы

```html
<header>Шапка: логотип, главное меню</header>
<nav>Навигация</nav>
<main>Основное содержимое — одно на страницу</main>
<aside>Дополнение: боковая колонка, реклама</aside>
<footer>Подвал: контакты, копирайт</footer>
```

Внутри `main` содержимое делят так:

| Тег | Когда использовать |
|---|---|
| `<article>` | Самостоятельный материал, который можно вынуть со страницы целиком: статья, карточка товара, комментарий |
| `<section>` | Смысловой раздел со своим заголовком |
| `<div>` | Смысла нет, нужна просто обёртка для стилей |

`<div>` и его строчный собрат `<span>` — не ошибка. Ошибка — брать их там, где есть подходящий по смыслу тег.

## Заголовки

Заголовки `<h1>`–`<h6>` образуют оглавление страницы.

- `<h1>` на странице один — её название.
- Уровни не пропускают: после `<h2>` идёт `<h3>`, а не `<h4>`.
- Уровень выбирают по структуре, а не по размеру шрифта. Размер меняется в CSS.

## Текст

```html
<p>Абзац. Внутри него <strong>важное</strong>, <em>с ударением</em>
и <a href="/about">ссылка</a>.</p>

<ul>
  <li>Пункт маркированного списка</li>
</ul>

<ol>
  <li>Пункт нумерованного списка</li>
</ol>

<time datetime="2024-03-15">15 марта</time>
```

Меню — это список ссылок, поэтому его верстают как `<nav>` со списком `<ul>` внутри.

## Ссылка или кнопка

Одна из самых частых ошибок вёрстки.

- **`<a href="...">`** — переход на другой адрес.
- **`<button type="button">`** — действие на этой же странице: открыть окно, добавить в корзину.

Кликабельный `<div>` не получает фокус с клавиатуры и не объявляется как кнопка. Его придётся долго чинить руками, а `<button>` умеет всё сразу.

## Картинки

```html
<img src="cat.jpg" alt="Рыжий кот спит на подоконнике" width="400" height="300">
```

Атрибут `alt` обязателен. Его текст увидят, если картинка не загрузилась, и услышат пользователи программ экранного доступа. Для чисто декоративных картинок пишут пустой `alt=""` — тогда их пропустят.

`width` и `height` сообщают размеры заранее, и страница не прыгает при загрузке.

## Блочные и строчные элементы

- **Блочные** (`div`, `p`, `h1`, `ul`, `section`…) занимают всю доступную ширину и начинаются с новой строки.
- **Строчные** (`span`, `a`, `strong`, `em`…) идут в строке текста и занимают столько места, сколько нужно содержимому.

Это поведение по умолчанию, и CSS может его поменять. Но вкладывать блочный элемент в строчный нельзя: `<span><div>…</div></span>` — ошибка разметки.

> **Как устроены задания по вёрстке.** В редакторе ты пишешь только содержимое страницы — то, что обычно лежит внутри `<body>`. Стили добавляются тегом `<style>` в начале. Под редактором — живой предпросмотр: на вкладке «Образец» видно, что должно получиться, а кнопки ширины показывают страницу на телефоне и планшете.
