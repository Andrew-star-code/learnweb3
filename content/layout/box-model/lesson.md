# Блочная модель

Каждый элемент на странице — прямоугольник. Из чего складывается его размер и расстояние до соседей, описывает блочная модель. Это основа любой раскладки: пока она непонятна, вёрстка превращается в подбор чисел наугад.

## Четыре слоя

Изнутри наружу:

1. **Содержимое** — текст, картинка. Размер задают `width` и `height`.
2. **`padding`** — внутренний отступ между содержимым и рамкой. Закрашивается фоном элемента.
3. **`border`** — рамка.
4. **`margin`** — внешний отступ до соседей. Всегда прозрачный.

```css
.card {
  width: 300px;
  padding: 20px;
  border: 1px solid #ccc;
  margin: 16px;
}
```

Короткая запись отступов читается по часовой стрелке, начиная сверху:

| Запись | Значение |
|---|---|
| `padding: 10px` | Со всех сторон |
| `padding: 10px 20px` | Сверху и снизу 10, слева и справа 20 |
| `padding: 10px 20px 30px 40px` | Сверху, справа, снизу, слева |

Есть и отдельные свойства: `margin-top`, `padding-left` и так далее.

## box-sizing: главная строчка

По умолчанию `width` задаёт ширину только содержимого. `padding` и `border` прибавляются сверху:

```text
width: 300px + padding: 20px × 2 + border: 1px × 2 = 342px на странице
```

Написал 300, получил 342 — раскладка разъезжается. Поэтому в начале любого проекта пишут:

```css
* {
  box-sizing: border-box;
}
```

С `border-box` свойство `width` означает полную ширину вместе с `padding` и `border`. Написал 300 — получил 300. Bootstrap и все современные проекты включают это по умолчанию.

## Ширина блока

Блочный элемент без `width` занимает всю ширину родителя. Ограничить его лучше через `max-width`, а не `width`:

```css
.page {
  max-width: 800px;   /* не шире 800, но на узком экране сожмётся */
  margin: 0 auto;     /* auto слева и справа — по центру */
}
```

`width: 800px` на экране шириной 360 даст горизонтальную прокрутку. `max-width: 800px` — нет. Пара `max-width` + `margin: 0 auto` — стандартный способ сделать центральную колонку.

## Схлопывание внешних отступов

Вертикальные `margin` соседних блоков не складываются, а берётся больший. Между абзацем с `margin-bottom: 20px` и следующим с `margin-top: 30px` будет 30 пикселей, а не 50.

Это задумано для текста, но в раскладке удивляет. Простое правило, которое снимает проблему: задавай вертикальные отступы в одну сторону, например только `margin-bottom`. А внутри flex- и grid-контейнеров (следующие уроки) отступы не схлопываются вообще, и там вместо `margin` используют `gap`.

## display

| Значение | Поведение |
|---|---|
| `block` | Вся ширина, с новой строки. `width`, `height`, все отступы работают |
| `inline` | В строке текста. `width`, `height` и вертикальные `margin` **не работают** |
| `inline-block` | В строке, но размеры и отступы работают — подходит для кнопок |
| `none` | Элемента нет на странице |

Если у ссылки или `span` не применяется ширина или отступ сверху — причина в `display: inline`.

## Оформление

```css
.card {
  border-radius: 8px;                           /* скруглённые углы; 50% — круг */
  box-shadow: 0 2px 8px rgb(0 0 0 / 15%);       /* тень: сдвиг x, сдвиг y, размытие, цвет */
  overflow: hidden;                             /* обрезать то, что не поместилось */
}
```

## Инструмент

В браузере нажми F12, выбери элемент на вкладке Elements — справа, во вкладке Computed, будет схема его блочной модели с реальными числами. Это первое, куда стоит смотреть, когда что-то не того размера.
