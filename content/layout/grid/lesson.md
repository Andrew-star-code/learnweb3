# Grid

Grid раскладывает элементы **по сетке из строк и столбцов**. Каталог товаров, галерея, раскладка страницы «шапка — боковая панель — содержимое — подвал» — задачи для него.

## Столбцы

Как и во flexbox, свойства пишутся у родителя.

```css
.catalog {
  display: grid;
  grid-template-columns: 200px 1fr 1fr;   /* три столбца */
  gap: 20px;
}
```

Элементы сами встают в ячейки по порядку, слева направо и сверху вниз. Строки создаются автоматически по мере надобности.

`fr` — доля свободного места. `1fr 1fr` — два равных столбца, `2fr 1fr` — первый вдвое шире. Свободное место считается после вычета фиксированных столбцов и промежутков.

`repeat` избавляет от повторов: `repeat(3, 1fr)` — то же, что `1fr 1fr 1fr`.

## Адаптивная сетка в одну строчку

```css
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 16px;
}
```

Читается так: «помести в ряд столько столбцов, сколько влезет, каждый не уже 200px, а оставшееся место раздели между ними поровну». На широком экране получится четыре столбца, на телефоне — один, и всё это без единого медиазапроса.

## Элемент на несколько ячеек

```css
.wide  { grid-column: span 2; }   /* занять два столбца */
.tall  { grid-row: span 2; }      /* занять две строки */
.full  { grid-column: 1 / -1; }   /* от первой линии до последней — на всю ширину */
```

## Именованные области

Раскладку страницы можно буквально нарисовать:

```css
.page {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  gap: 16px;
}

.page header { grid-area: header; }
.page aside  { grid-area: sidebar; }
.page main   { grid-area: main; }
.page footer { grid-area: footer; }
```

Каждая строка в кавычках — ряд сетки, каждое слово — ячейка. Повторённое имя растягивает область на несколько ячеек.

## Выравнивание

`gap`, `justify-content` и `align-items` работают так же, как во flexbox. Центрирование в grid — самое короткое из возможных:

```css
.stage {
  display: grid;
  place-items: center;
}
```

## Grid или Flexbox

| Задача | Что брать |
|---|---|
| Ряд элементов: меню, кнопки, шапка | Flexbox |
| Сетка карточек с ровными столбцами | Grid |
| Раскладка всей страницы | Grid |
| Центрирование одного элемента | Любой |
| Размер элементов зависит от содержимого | Flexbox |
| Размер элементов задаёт сетка | Grid |

Они не конкуренты и постоянно используются вместе: страница на grid, шапка внутри неё на flexbox.
