# Bootstrap 3/4 и jQuery в легаси

В старых проектах ты почти наверняка встретишь Bootstrap 3 или 4 в паре с jQuery. Классы похожи на современные, но не совпадают, и код, скопированный из свежей документации, там не заработает. Этот урок — о том, как опознать версию и как читать такой код.

## Как узнать версию

- Открой подключённый файл `bootstrap.css` или `bootstrap.min.css`: в первой строке комментарий с версией.
- Посмотри на подключённые скрипты: `jquery.js` перед `bootstrap.js` — это версия 3 или 4. Bootstrap 5 от jQuery не зависит.
- Посмотри на разметку: признаки версий в таблице ниже.

## Что изменилось

| Что | Bootstrap 3 | Bootstrap 4 | Bootstrap 5 |
|---|---|---|---|
| jQuery | обязателен | обязателен | не нужен |
| Сетка | на `float` | на flexbox | на flexbox |
| Самая узкая колонка | `col-xs-6` | `col-6` | `col-6` |
| Блок с рамкой | `panel`, `well` | `card` | `card` |
| Серая кнопка | `btn-default` | `btn-secondary` | `btn-secondary` |
| Отступ слева | своих утилит нет | `ml-2`, `pl-2` | `ms-2`, `ps-2` |
| Прижать вправо | `pull-right` | `float-right` | `float-end` |
| Текст вправо | `text-right` | `text-right` | `text-end` |
| Скрыть на телефоне | `hidden-xs` | `d-none d-sm-block` | `d-none d-sm-block` |
| Резиновая картинка | `img-responsive` | `img-fluid` | `img-fluid` |
| Группа поля формы | `form-group` | `form-group` | `mb-3` |
| Атрибуты поведения | `data-toggle` | `data-toggle` | `data-bs-toggle` |
| Иконки | Glyphicons в комплекте | нет | нет (отдельно Bootstrap Icons) |
| Метка | `label label-primary` | `badge badge-primary` | `badge text-bg-primary` |

Из-за сетки на `float` в Bootstrap 3 колонки разной высоты «цепляются» друг за друга, и в старом коде встречается `<div class="clearfix"></div>` — костыль, который возвращает перенос на новую строку.

## Главное правило

**Не смешивай версии.** В проекте подключена одна версия, и классы должны быть от неё. Если в проекте Bootstrap 3, а ты добавил блок с `d-flex` и `ms-2`, он не заработает — и ошибки при этом не будет, классы просто ничего не значат.

Когда нужно доработать старую страницу:

1. Определи версию.
2. Открой документацию **этой версии**: у Bootstrap есть архив по адресам вида `getbootstrap.com/docs/3.4/` и `getbootstrap.com/docs/4.6/`.
3. Найди на той же странице или в проекте похожий блок и сделай по его образцу.

## jQuery: как читать

jQuery — библиотека, которая в 2010-х была стандартным способом работать со страницей. Сейчас всё то же умеет сам браузер, но кода на jQuery написано очень много.

Вся библиотека — одна функция `$`. Она принимает селектор CSS и возвращает набор найденных элементов, у которого есть методы.

```js
$('.btn-save').on('click', function () {
  $(this).addClass('disabled').text('Сохраняю…');
});
```

Читается так: найти элементы `.btn-save` → повесить обработчик клика → внутри него нажатой кнопке (`this`) добавить класс и заменить текст. Методы вызываются цепочкой, потому что каждый возвращает тот же набор.

| jQuery | Что делает | То же без jQuery |
|---|---|---|
| `$('.item')` | Найти элементы | `document.querySelectorAll('.item')` |
| `$('#save')` | Найти по id | `document.querySelector('#save')` |
| `.on('click', fn)` | Обработчик события | `.addEventListener('click', fn)` |
| `.addClass('a')`, `.removeClass('a')`, `.toggleClass('a')` | Классы | `.classList.add('a')`, `.remove`, `.toggle` |
| `.text('…')`, `.html('…')` | Заменить содержимое | `.textContent = '…'`, `.innerHTML = '…'` |
| `.val()` | Значение поля формы | `.value` |
| `.attr('href')` | Прочитать атрибут | `.getAttribute('href')` |
| `.hide()`, `.show()` | Скрыть, показать | `.hidden = true`, `.hidden = false` |
| `$(document).ready(fn)` или `$(fn)` | Выполнить, когда страница готова | `document.addEventListener('DOMContentLoaded', fn)` |
| `$.ajax(…)`, `$.get(…)`, `$.post(…)` | Запрос к серверу | `fetch(…)` |

Правая колонка — это то, что мы подробно разберём в блоке «JavaScript в браузере». Сейчас достаточно уметь прочитать левую.

Две вещи, которые часто сбивают с толку:

- `$('.item')` возвращает не элемент, а **набор**, и метод применяется ко всем найденным сразу. Цикл не нужен.
- Если ничего не найдено, ошибки не будет: метод просто применится к пустому набору. Опечатка в селекторе проходит молча.

Компоненты Bootstrap 3 и 4 вызываются как методы jQuery: `$('#confirm').modal('show')`. В пятой версии вместо этого `new bootstrap.Modal('#confirm').show()`.

## Трогать или переписывать

Переводить работающий проект с Bootstrap 3 на 5 «заодно» не стоит: меняются сотни классов и вся раскладка. Это отдельная большая задача с отдельной проверкой каждой страницы. В легаси действует правило: правь в том стиле, в котором написано, и меняй ровно столько, сколько нужно для задачи.
