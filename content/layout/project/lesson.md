# Проект: страница каталога

Итог блока — страница каталога кофейни, свёрстанная с нуля, без Bootstrap. В ней сходится всё: семантика, блочная модель, flexbox для шапки, grid для карточек, медиазапросы.

Образец — на вкладке предпросмотра. Посмотри его на всех трёх ширинах, прежде чем начинать.

## Требования

### Разметка

- Шапка `<header class="site-header">`: название «Зерно» в элементе с классом `logo` и навигация `<nav>` с тремя ссылками — «Каталог», «Доставка», «Контакты».
- Основное содержимое `<main class="container">`: заголовок первого уровня «Каталог» и блок `<div class="catalog">`.
- В каталоге шесть карточек `<article class="card">`. В каждой: заголовок второго уровня с названием, абзац с классом `price` и кнопка `<button type="button" class="btn">В корзину</button>`.
- Подвал `<footer class="site-footer">` с текстом «© Кофейня «Зерно»».

Названия и цены придумай сам или возьми с образца.

### Общие стили

- Для всех элементов `box-sizing: border-box`.
- У `body` нет внешних отступов, шрифт без засечек.
- В `:root` объявлена переменная `--accent` со значением `rgb(47, 111, 79)`.

### Шапка

- Flex-контейнер: логотип слева, навигация справа, по вертикали по центру.
- Внутренние отступы 16px.
- Ссылки навигации в ряд с промежутком 16px.

### Содержимое

- `.container` не шире 960px, по центру окна, с внутренними отступами 16px слева и справа.
- `.catalog` — сетка с промежутком 16px: один столбец на телефоне, два от 576px, три от 992px.

### Карточка

- Внутренний отступ 16px, рамка 1px, скругление 8px.
- Кнопка занимает всю ширину карточки: фон цвета `--accent`, белый текст, без рамки, скругление 6px, внутренние отступы 10px.

### Подвал

- Текст по центру, внутренние отступы 16px.

### Адаптивность

- На ширине 360px нет горизонтальной прокрутки.

## Как подойти

Не пытайся написать всё сразу. Порядок, который работает почти всегда:

1. **Сначала вся разметка без единого стиля.** Проверь, что тесты на структуру проходят.
2. **Общие стили**: `box-sizing`, `body`, переменная.
3. **Мобильная раскладка сверху вниз**: шапка, контейнер, каталог в один столбец, карточка, подвал.
4. **Медиазапросы** для двух и трёх столбцов.
5. Пройдись по ширинам 360, 768 и на всю ширину.

Тесты идут в том же порядке, что и требования. Готового решения у проекта нет, но есть подсказки и образец.
