# Flexbox

Flexbox раскладывает элементы **в один ряд или в одну колонку** и распределяет между ними свободное место. Шапка с логотипом слева и меню справа, ряд карточек, кнопки в строке формы, центрирование — всё это он.

## Контейнер и элементы

Свойство `display: flex` пишется у **родителя**. Его прямые потомки становятся flex-элементами и выстраиваются в ряд.

```css
.toolbar {
  display: flex;
  gap: 16px;          /* расстояние между элементами */
}
```

## Две оси

У контейнера есть главная ось (вдоль неё идут элементы) и поперечная.

| Свойство контейнера | За что отвечает | Частые значения |
|---|---|---|
| `flex-direction` | Направление главной оси | `row` (по умолчанию), `column` |
| `justify-content` | Распределение по **главной** оси | `flex-start`, `center`, `flex-end`, `space-between` |
| `align-items` | Выравнивание по **поперечной** оси | `stretch` (по умолчанию), `center`, `flex-start`, `flex-end` |
| `flex-wrap` | Перенос на новую строку | `nowrap` (по умолчанию), `wrap` |
| `gap` | Промежутки между элементами | `16px` |

При `flex-direction: row` главная ось горизонтальна: `justify-content` двигает по горизонтали, `align-items` — по вертикали. При `column` всё наоборот. Если свойство «не работает» — скорее всего, перепутана ось.

## Готовые рецепты

**Логотип слева, меню справа, по вертикали по центру:**

```css
.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
```

**Центрирование по обеим осям:**

```css
.stage {
  display: flex;
  justify-content: center;
  align-items: center;
}
```

**Один элемент прижать к краю.** `margin-left: auto` забирает всё свободное место слева от элемента:

```css
.logout { margin-left: auto; }
```

## Свойства элементов

| Свойство | Что делает |
|---|---|
| `flex: 1` | Элемент растягивается и делит свободное место с другими такими же поровну |
| `flex: 0 0 200px` | Жёсткая ширина 200px: не растёт и не сжимается |
| `align-self` | Своё выравнивание по поперечной оси |

**Равные колонки:**

```css
.cards { display: flex; gap: 16px; }
.card  { flex: 1; }
```

**Боковая панель фиксированной ширины и тянущееся содержимое:**

```css
.sidebar { flex: 0 0 240px; }
.content { flex: 1; }
```

**Подвал, прижатый к низу окна:**

```css
.page {
  display: flex;
  flex-direction: column;
  min-height: 100vh;     /* не ниже высоты окна */
}
.page main { flex: 1; }  /* main забирает всё свободное место */
```

## Перенос

По умолчанию элементы не переносятся: они сжимаются, а если не могут — вылезают за контейнер. `flex-wrap: wrap` разрешает перенос на следующую строку. Так делают списки тегов и простые адаптивные ряды.

## Чего flexbox не делает

Он управляет одним измерением. Если нужна сетка, где элементы выровнены и по строкам, и по столбцам, — это Grid, следующий урок.
