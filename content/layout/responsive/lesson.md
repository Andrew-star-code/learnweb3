# Адаптивность

Одну и ту же страницу открывают на телефоне шириной 360 пикселей и на мониторе шириной 2000. Адаптивная вёрстка — это страница, которая удобна в обоих случаях.

## Сначала — обязательная строчка

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

Она стоит в `<head>` каждой страницы. Без неё телефон считает, что страница рассчитана на широкий экран, и показывает её уменьшенной целиком — с мелким нечитаемым текстом. В заданиях платформы эта строка уже добавлена.

## Резиновая основа

Большая часть адаптивности — не медиазапросы, а отказ от жёстких размеров.

| Вместо | Пиши |
|---|---|
| `width: 960px` | `max-width: 960px` |
| ширина картинки в пикселях | `max-width: 100%; height: auto;` |
| три столбца фиксированной ширины | `repeat(auto-fit, minmax(240px, 1fr))` |
| ряд без переноса | `flex-wrap: wrap` |

Строчка про картинки стоит того, чтобы запомнить её наизусть: без неё большая картинка вылезает за экран и создаёт горизонтальную прокрутку.

```css
img {
  max-width: 100%;
  height: auto;
}
```

## Медиазапросы

Когда резиновости мало и раскладку нужно именно перестроить, пишут условие на ширину окна:

```css
.cards {
  display: flex;
  flex-direction: column;       /* телефон: карточки друг под другом */
  gap: 16px;
}

@media (min-width: 768px) {
  .cards {
    flex-direction: row;        /* от 768px: в ряд */
  }
}
```

Правила внутри `@media` применяются, только когда условие выполнено. Ширина, на которой раскладка меняется, называется контрольной точкой.

## Сначала мобильные

Подход «mobile first»: базовые стили пишутся для самого узкого экрана, а медиазапросы с `min-width` добавляют изменения для более широких.

Почему так, а не наоборот:

- Мобильная раскладка проще — обычно всё в одну колонку. К простому легче добавлять, чем из сложного вычитать.
- Правила не приходится отменять. При обратном подходе половина мобильных стилей — это сброс десктопных.
- Так устроен Bootstrap, и его классы вроде `col-md-6` читаются именно так: «от средней ширины и выше — половина».

Типичные контрольные точки — те же, что в Bootstrap 5:

| Название | Ширина от | Устройства |
|---|---|---|
| `sm` | 576px | Большие телефоны |
| `md` | 768px | Планшеты |
| `lg` | 992px | Ноутбуки |
| `xl` | 1200px | Мониторы |

Но ориентироваться лучше на содержимое: ставь точку там, где раскладка начинает выглядеть плохо.

## Показать и скрыть

```css
.menu-button { display: block; }

@media (min-width: 768px) {
  .menu-button { display: none; }    /* на широком экране кнопка меню не нужна */
}
```

## Плавные размеры

`clamp(минимум, желаемое, максимум)` позволяет размеру плавно меняться вместе с шириной окна в заданных границах:

```css
h1 { font-size: clamp(1.5rem, 4vw, 3rem); }
```

`vw` — один процент ширины окна.

## Как проверять

- В заданиях — кнопки ширины над предпросмотром.
- В браузере — F12 и значок телефона на панели: режим, в котором окно можно тянуть за край или выбрать конкретное устройство.
- Главный признак ошибки — горизонтальная полоса прокрутки на узком экране.
