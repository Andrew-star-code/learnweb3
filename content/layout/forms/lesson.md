# Формы

Форма — способ отправить данные от человека на сервер. Всё, что ты позже будешь принимать в PHP через `$_POST` и `$_GET`, начинается здесь.

## Устройство формы

```html
<form action="/login" method="post">
  <label for="email">Почта</label>
  <input type="email" id="email" name="email" required>

  <button type="submit">Войти</button>
</form>
```

- `action` — адрес, куда уйдут данные.
- `method` — способ отправки. `get` дописывает данные в адрес (`/search?q=кофе`) и подходит для поиска и фильтров. `post` передаёт их в теле запроса и нужен для всего, что меняет данные или содержит секреты.
- **`name`** — имя, под которым значение придёт на сервер. **Поле без `name` не отправляется вообще.** Это самая частая причина «форма отправилась, а данных нет».

## Подпись поля

У каждого поля должна быть подпись `<label>`, связанная с ним: `for` у подписи совпадает с `id` у поля.

Связь даёт две вещи: щелчок по подписи ставит курсор в поле (или отмечает флажок), а программа экранного доступа зачитывает, что это за поле.

`placeholder` подписью не является: он исчезает, как только человек начинает печатать.

## Виды полей

| Поле | Разметка |
|---|---|
| Строка текста | `<input type="text">` |
| Почта, телефон, адрес сайта | `type="email"`, `type="tel"`, `type="url"` |
| Пароль | `type="password"` |
| Число | `type="number" min="1" max="10"` |
| Дата | `type="date"` |
| Флажок (да или нет) | `type="checkbox"` |
| Один вариант из нескольких | `type="radio"` — у всех вариантов одинаковый `name` |
| Многострочный текст | `<textarea>` |
| Выпадающий список | `<select>` с вариантами `<option value="...">` |

Правильный `type` — это не формальность. На телефоне для `email` покажется клавиатура с собачкой, для `number` — цифровая, а браузер сам проверит формат.

У флажков и переключателей на сервер уходит значение атрибута `value`. Переключатели объединяет в группу одинаковый `name`: выбрать можно только один из группы.

```html
<input type="radio" id="courier" name="delivery" value="courier">
<label for="courier">Курьер</label>

<input type="radio" id="pickup" name="delivery" value="pickup">
<label for="pickup">Самовывоз</label>
```

Группу связанных полей оборачивают в `<fieldset>` с заголовком `<legend>`.

## Проверка в браузере

| Атрибут | Что проверяет |
|---|---|
| `required` | Поле заполнено |
| `minlength`, `maxlength` | Длина текста |
| `min`, `max` | Границы числа или даты |
| `pattern` | Соответствие регулярному выражению |

Браузер не отправит форму, пока проверки не пройдены, и сам покажет подсказку.

> Проверка в браузере — удобство для человека, а не защита. Запрос можно отправить в обход формы, поэтому **сервер обязан проверять всё заново**. К этому мы вернёмся в блоках про PHP и безопасность.

## Кнопки

- `<button type="submit">` — отправляет форму. Это значение по умолчанию: кнопка внутри формы без `type` тоже её отправит.
- `<button type="button">` — ничего не отправляет, нужна для действий через JavaScript.

Всегда указывай `type` явно — иначе кнопка «Показать пароль» внезапно отправит форму.
