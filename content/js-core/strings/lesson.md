# Строки

Почти всё, что приходит в программу извне, — строки: поля форм, адреса страниц, содержимое файлов. Поэтому умение разобрать строку на части и собрать обратно нужно постоянно.

## Строку нельзя изменить

Строки неизменяемы. Ни один метод не меняет исходную строку — он возвращает новую.

```js
let name = 'аня';
name.toUpperCase();           // результат потерян
console.log(name);            // 'аня'

name = name.toUpperCase();    // вот так
```

Забытое присваивание — самая частая ошибка при работе со строками.

## Основные методы

| Задача | Метод | Пример |
|---|---|---|
| Длина | `length` | `'кот'.length` → `3` |
| Символ по номеру | `[i]`, `at(i)` | `'кот'[0]` → `'к'`, `'кот'.at(-1)` → `'т'` |
| Кусок строки | `slice(from, to)` | `'привет'.slice(0, 3)` → `'при'`, `'привет'.slice(-3)` → `'вет'` |
| Есть ли подстрока | `includes`, `startsWith`, `endsWith` | `'a@b.c'.includes('@')` → `true` |
| Где подстрока | `indexOf` | `'a=b'.indexOf('=')` → `1`, если нет — `-1` |
| Регистр | `toUpperCase`, `toLowerCase` | |
| Убрать пробелы по краям | `trim` | `'  да '.trim()` → `'да'` |
| Заменить | `replace`, `replaceAll` | `'a-b-c'.replaceAll('-', ' ')` → `'a b c'` |
| Дополнить до длины | `padStart`, `padEnd` | `'7'.padStart(2, '0')` → `'07'` |
| Повторить | `repeat` | `'*'.repeat(3)` → `'***'` |

`replace` со строкой в первом аргументе заменяет только **первое** вхождение. Чтобы заменить все — `replaceAll`.

В `slice(from, to)` элемент с номером `to` в результат не входит. Отрицательные числа отсчитываются с конца.

## Разобрать и собрать

Самая полезная пара методов:

```js
'2024-03-15'.split('-');           // ['2024', '03', '15']
['15', '03', '2024'].join('.');    // '15.03.2024'
```

Типовой ход: `split` → обработать массив методами массивов → `join`.

```js
const title = 'привет большой мир'
  .split(' ')
  .map((word) => word[0].toUpperCase() + word.slice(1))
  .join(' ');                      // 'Привет Большой Мир'
```

## Сравнение

`===` сравнивает строки посимвольно и с учётом регистра: `'Аня' === 'аня'` даёт `false`. Если регистр не важен, приведи обе строки к одному: `a.toLowerCase() === b.toLowerCase()`.

Для сортировки по алфавиту используй `a.localeCompare(b)` — операторы `<` и `>` сравнивают коды символов, и, например, «ё» окажется после «я».

## Регулярные выражения: первое знакомство

Регулярное выражение — шаблон для поиска в тексте. Записывается между косыми чертами.

```js
/\d/.test('abc1');                  // true — есть ли цифра
'a  b   c'.split(/\s+/);            // ['a', 'b', 'c'] — делить по любому числу пробелов
'8 (900) 123'.replace(/\D/g, '');   // '8900123' — убрать всё, кроме цифр
```

`\d` — цифра, `\D` — не цифра, `\s` — пробельный символ, `+` — один или больше, флаг `g` — все вхождения. Подробно регулярные выражения разберём, когда дойдём до валидации форм.
