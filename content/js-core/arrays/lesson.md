# Массивы и их методы

Массив — упорядоченный список значений. Элементы нумеруются с нуля, длина лежит в `length`.

```js
const fruits = ['яблоко', 'груша'];
fruits[0];            // 'яблоко'
fruits.length;        // 2
fruits[5];            // undefined — ошибки нет, просто пусто
fruits.at(-1);        // 'груша' — последний элемент
```

## Добавить и убрать

| Метод | Что делает | Возвращает |
|---|---|---|
| `push(x)` | добавляет в конец | новую длину |
| `pop()` | убирает с конца | убранный элемент |
| `unshift(x)` | добавляет в начало | новую длину |
| `shift()` | убирает из начала | убранный элемент |

## Методы вместо циклов

Четыре приёма из блока «Как писать с нуля» есть в виде готовых методов. Каждый принимает функцию и вызывает её для каждого элемента.

```js
const prices = [100, 250, 40];

// Преобразование → map
prices.map((p) => p * 2);                 // [200, 500, 80]

// Отбор → filter
prices.filter((p) => p >= 100);           // [100, 250]

// Накопление → reduce
prices.reduce((sum, p) => sum + p, 0);    // 390

// Поиск одного элемента → find
prices.find((p) => p > 200);              // 250, а если нет — undefined
```

`reduce` получает функцию с двумя параметрами — накопленное значение и текущий элемент — и начальное значение накопителя. **Начальное значение указывай всегда**: без него `reduce` на пустом массиве падает с ошибкой.

Ещё три метода отвечают на вопросы «да или нет»:

```js
prices.includes(40);            // true — есть ли такое значение
prices.some((p) => p > 200);    // true — подходит ли хотя бы один
prices.every((p) => p > 50);    // false — подходят ли все
```

Методы можно соединять в цепочку, потому что `map` и `filter` возвращают массив:

```js
const names = users.filter((u) => u.active).map((u) => u.name);
```

## Кто меняет исходный массив

Это главный источник трудноуловимых ошибок. Одни методы возвращают новый массив, другие переделывают тот, у которого вызваны.

| Не меняют (возвращают новое) | Меняют исходный массив |
|---|---|
| `map`, `filter`, `slice`, `concat` | `push`, `pop`, `shift`, `unshift` |
| `toSorted`, `toReversed` | `sort`, `reverse`, `splice` |

Чтобы безопасно отсортировать, сначала сделай копию: `[...items].sort(...)`.

`slice(from, to)` вырезает кусок, не трогая исходный массив. `splice` с похожим названием удаляет элементы прямо из него — не путай.

## Сортировка

```js
[10, 9, 1].sort();                    // [1, 10, 9] — неожиданно
[10, 9, 1].sort((a, b) => a - b);     // [1, 9, 10]
```

Без аргумента `sort` сравнивает элементы **как строки**, а строка `'10'` идёт раньше `'9'`. Для чисел всегда передавай функцию сравнения: `a - b` — по возрастанию, `b - a` — по убыванию.

Для строк с кириллицей используй `a.localeCompare(b)`.

## Копия и разбор на части

```js
const copy = [...prices];               // копия массива
const more = [...prices, 500];          // копия с добавленным элементом
const [first, second] = prices;         // first = 100, second = 250
```
