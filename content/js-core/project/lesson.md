# Проект: учёт расходов

Первый проект. Здесь нет новой теории — нужно собрать вместе всё, что было в блоке: строки, массивы, объекты, функции, ошибки.

## Задача

Есть выгрузка расходов в текстовом виде. Каждая строка — одна трата: дата, категория и сумма через точку с запятой.

```text
2024-03-01;еда;450
2024-03-01;транспорт;60
2024-03-02;еда;1200.50
2024-03-03;развлечения;800
```

Нужно написать набор функций, который превращает такой текст в отчёт:

```text
еда: 1650.50 ₽
развлечения: 800.00 ₽
транспорт: 60.00 ₽
Итого: 2510.50 ₽
```

## Требования

**1. `parseExpense(line)`** — разбирает одну строку и возвращает объект `{ date, category, amount }`.

- `amount` — число, а не строка.
- Пробелы вокруг значений убираются: `' еда '` → `'еда'`.
- Если в строке не три части, бросает `Error` с текстом `Неверный формат строки`.
- Если сумма не число или меньше нуля, бросает `Error` с текстом `Неверная сумма`.

**2. `parseExpenses(text)`** — разбирает весь текст и возвращает массив объектов.

- Пустые строки пропускаются.
- Если какая-то строка неверна, бросает `Error`, в тексте которого есть номер строки: `Строка 3: Неверная сумма`. Строки нумеруются с единицы, пустые тоже считаются.

**3. `totalByCategory(expenses)`** — возвращает объект, где ключ — категория, значение — сумма трат по ней.

**4. `formatReport(expenses)`** — возвращает текст отчёта.

- По строке на категорию в виде `категория: 1650.50 ₽`.
- Категории идут по убыванию суммы.
- Последняя строка — `Итого: 2510.50 ₽`.
- Строки разделены символом `\n`.
- Для пустого списка отчёт состоит из одной строки `Итого: 0.00 ₽`.

## Как подойти

Это четыре отдельные задачи, а не одна большая. Каждая следующая функция пользуется предыдущими.

1. Начни с плана — первое задание ниже.
2. Пиши по одной функции. Написал — вызови её с примером, выведи результат через `console.log`, убедись, что всё верно. Только потом берись за следующую.
3. Нажимай «Проверить» в любой момент: тесты — это чек-лист приёмки, по ним видно, что уже готово.

Готового решения у проекта нет. Подсказки есть, но попробуй сначала обойтись без них: если застрял, вернись к методу — пример, руками, шаги, код.
