# Переменные и типы

## let и const

```js
const name = 'Аня';   // значение не будет заменено
let age = 30;         // значение можно заменить
age = 31;
```

Рабочее правило: **всегда пиши `const`, пока не понадобится присвоить заново, — тогда меняй на `let`.** Так по объявлению сразу видно, меняется переменная дальше или нет.

`var` — старый способ объявления с неочевидными правилами видимости. В новом коде его не пишут, но в легаси он встречается постоянно, так что узнавать его нужно.

> `const` запрещает только присваивание заново. Содержимое массива или объекта в `const`-переменной менять можно: `const list = []; list.push(1);` — работает.

## Типы значений

| Тип | Примеры | `typeof` |
|---|---|---|
| Число | `42`, `3.14`, `NaN`, `Infinity` | `'number'` |
| Строка | `'текст'`, `"текст"`, `` `текст` `` | `'string'` |
| Логический | `true`, `false` | `'boolean'` |
| «Не задано» | `undefined` | `'undefined'` |
| «Пусто намеренно» | `null` | `'object'` — историческая ошибка языка |
| Объект | `{ a: 1 }`, `[1, 2]`, функции | `'object'`, для функций `'function'` |

Есть ещё `bigint` и `symbol`, но в повседневном коде они редки.

Две особенности, о которые спотыкаются все:

- `typeof null` возвращает `'object'`. Проверять на `null` нужно прямым сравнением: `value === null`.
- `typeof []` тоже `'object'`. Массив определяют так: `Array.isArray(value)`.

## Строки

Три вида кавычек. Обратные позволяют вставлять значения и переносить строки:

```js
const user = 'Аня';
const count = 3;
const message = `Привет, ${user}! У тебя ${count} новых сообщения.`;
```

Внутри `${}` может стоять любое выражение: `${price * qty}`, `${name.toUpperCase()}`.

## Преобразование типов

Явное преобразование — когда ты сам просишь:

```js
Number('42')      // 42
Number('4 2')     // NaN — не получилось
Number('')        // 0 — неожиданно, стоит помнить
String(42)        // '42'
Boolean('текст')  // true
```

Неявное — когда язык делает это молча. Главный источник сюрпризов — плюс:

```js
'5' + 3    // '53' — есть строка, значит склейка
'5' - 3    // 2    — минус бывает только числовым
'5' * '2'  // 10
```

`NaN` («не число») получается, когда числовая операция не удалась. Он не равен ничему, даже самому себе, поэтому проверяют его только функцией: `Number.isNaN(value)`.

## Сравнение: только ===

```js
5 === '5'   // false — разные типы
5 == '5'    // true  — строка молча превращена в число
0 == ''     // true
null == undefined  // true
```

`==` перед сравнением приводит типы по сложным правилам. **Пиши `===` и `!==` всегда** — тогда сравнение делает ровно то, что написано.

## Истинные и ложные значения

В условии `if` любое значение превращается в `true` или `false`. Ложных значений всего шесть, их стоит выучить:

```js
false, 0, '', null, undefined, NaN
```

Всё остальное истинно — включая `'0'`, `'false'`, пустой массив `[]` и пустой объект `{}`.
