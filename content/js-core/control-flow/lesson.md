# Условия и циклы

## if, else if, else

```js
if (score >= 90) {
  grade = 'отлично';
} else if (score >= 70) {
  grade = 'хорошо';
} else {
  grade = 'надо подтянуть';
}
```

Условия проверяются сверху вниз, выполняется первая подошедшая ветка, остальные пропускаются. Поэтому **порядок важен**: более строгое условие ставят выше.

### Ранний выход

Внутри функции вместо цепочки `else` часто удобнее сразу возвращать результат:

```js
function grade(score) {
  if (score >= 90) return 'отлично';
  if (score >= 70) return 'хорошо';
  return 'надо подтянуть';
}
```

Тот же приём убирает вложенность: сначала отсекаем «плохие» случаи, потом пишем основную логику без отступов.

## Тернарный оператор

Короткая запись `if/else`, когда нужно выбрать одно из двух значений:

```js
const label = count === 1 ? 'товар' : 'товаров';
```

Для выбора значения он хорош. Для вложенных условий и действий — нет: читается плохо, лучше обычный `if`.

## Логические операторы

| Оператор | Смысл | Пример |
|---|---|---|
| `&&` | И — истинно, если истинны оба | `age >= 18 && hasTicket` |
| `\|\|` | ИЛИ — истинно, если истинен хотя бы один | `isAdmin \|\| isOwner` |
| `!` | НЕ — переворачивает | `!isBlocked` |

`||` и `??` используют ещё и для **значения по умолчанию**, и тут есть важная разница:

```js
const a = 0 || 10;    // 10 — || отбрасывает любое ложное значение, включая 0 и ''
const b = 0 ?? 10;    // 0  — ?? отбрасывает только null и undefined
```

Если ноль или пустая строка — допустимые значения (количество, цена, необязательный комментарий), нужен `??`.

## Циклы

**`for...of`** — пройти по элементам массива или символам строки. Используй его по умолчанию:

```js
for (const item of items) {
  console.log(item);
}
```

**`for` со счётчиком** — когда нужен номер шага или диапазон чисел:

```js
for (let i = 1; i <= 5; i++) {
  console.log(i);          // 1, 2, 3, 4, 5
}
```

Три части в скобках: начало; условие продолжения; что делать после каждого шага.

**`while`** — когда заранее неизвестно, сколько будет шагов:

```js
let n = 100;
while (n > 1) {
  n = n / 2;
}
```

В теле `while` обязательно должно меняться то, что проверяется в условии. Иначе цикл не закончится никогда.

### break и continue

- `break` — выйти из цикла совсем. Полезен, когда искомое найдено и дальше смотреть незачем.
- `continue` — пропустить остаток текущего шага и перейти к следующему.

> Есть ещё `for...in`. Он перебирает **ключи объекта**, а не элементы массива. Для массивов его не используют — это частая ошибка новичков.
