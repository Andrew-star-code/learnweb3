# Функции

Функция — это именованный шаг плана. Когда в декомпозиции появляется шаг «проверить, есть ли в пароле цифра», это готовая заявка на функцию `hasDigit(password)`.

## Три способа записи

```js
// 1. Объявление функции
function add(a, b) {
  return a + b;
}

// 2. Функция как значение переменной
const add2 = function (a, b) {
  return a + b;
};

// 3. Стрелочная функция
const add3 = (a, b) => a + b;
```

Практическая разница между первой и остальными: объявленную через `function` можно вызывать выше по коду, чем она написана. Остальные — только после строки с объявлением.

### Стрелочные функции: две формы

```js
const double = (x) => x * 2;        // без фигурных скобок: результат возвращается сам

const double2 = (x) => {            // с фигурными скобками: нужен return
  const result = x * 2;
  return result;
};
```

Фигурные скобки без `return` — одна из самых частых ошибок: `(x) => { x * 2 }` возвращает `undefined`.

## return

- `return` завершает функцию немедленно. Код после него не выполняется.
- Функция без `return` (или не дошедшая до него) возвращает `undefined`.
- **Вывести и вернуть — разные вещи.** `console.log(result)` показывает значение человеку. `return result` отдаёт его коду, который вызвал функцию. Если функция только выводит, её результат нельзя сложить, сохранить или проверить.

## Параметры

```js
function greet(name = 'гость') {     // значение по умолчанию
  return `Привет, ${name}!`;
}

greet('Аня');   // 'Привет, Аня!'
greet();        // 'Привет, гость!'
```

Если аргумент не передан и значения по умолчанию нет, параметр равен `undefined`. Ошибки при этом не будет — она появится позже, в неожиданном месте.

## Область видимости

Переменная, объявленная внутри функции или блока `{}`, снаружи не видна. А вот наружу функция смотреть может:

```js
const rate = 0.2;

function tax(amount) {
  const result = amount * rate;    // rate виден изнутри
  return result;
}

console.log(result);               // ReferenceError: result снаружи не существует
```

Чем меньше функция зависит от внешних переменных, тем проще её проверить и использовать заново. Идеал — **чистая функция**: результат зависит только от аргументов, и она ничего не меняет снаружи.

## Функция как значение

Функцию можно передать в другую функцию, как число или строку. Такой аргумент называют колбэком:

```js
function repeat(times, action) {
  for (let i = 0; i < times; i++) {
    action(i);                     // вызываем то, что передали
  }
}

repeat(3, (i) => console.log(`шаг ${i}`));
```

Обрати внимание: передаётся `action`, а не `action()`. Скобки — это вызов. Без скобок — сама функция.

На этом построены методы массивов (`map`, `filter`), обработчики событий и вся асинхронность — они впереди.

## Как делить код на функции

- Одна функция — одно дело. Если в описании функции есть союз «и», это, скорее всего, две функции.
- Имя — глагол, отвечающий на вопрос «что делает»: `calculateTotal`, `isValid`, `formatDate`.
- Функции, которые отвечают «да или нет», называют с `is` или `has`: `isEmpty`, `hasDigit`.
