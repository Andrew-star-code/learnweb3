# Замыкания

Замыкание звучит как сложная тема, но за ним стоит одно простое правило:

**Функция помнит переменные того места, где она была создана, — и может пользоваться ими даже после того, как это место завершило работу.**

## Счётчик

```js
function makeCounter() {
  let count = 0;              // переменная живёт внутри makeCounter

  return function () {
    count++;                  // внутренняя функция её видит
    return count;
  };
}

const counter = makeCounter();
counter();   // 1
counter();   // 2
```

`makeCounter` уже завершилась, но её переменная `count` не исчезла: на неё ссылается возвращённая функция. Функция вместе с переменными, которые она помнит, и называется замыканием.

Каждый вызов `makeCounter` создаёт **свою** переменную `count`:

```js
const a = makeCounter();
const b = makeCounter();
a(); a();   // 1, 2
b();        // 1 — у b свой счётчик
```

## Зачем это нужно

**Приватное состояние.** До `count` нельзя добраться снаружи — только через возвращённую функцию. Никакой другой код не сможет его случайно испортить.

**Функции с настройкой.** Функция, которая создаёт другие функции:

```js
function makeMultiplier(factor) {
  return (x) => x * factor;      // помнит factor
}

const double = makeMultiplier(2);
const triple = makeMultiplier(3);
double(5);   // 10
triple(5);   // 15
```

**Колбэки.** Обработчик клика, функция в `map`, таймер — все они выполняются позже и в другом месте, но видят переменные, рядом с которыми были написаны. Ты уже пользовался этим:

```js
function above(numbers, limit) {
  return numbers.filter((n) => n > limit);   // стрелка помнит limit
}
```

## Объект с приватными данными

Можно вернуть не одну функцию, а объект с несколькими. Все они разделяют одни и те же переменные:

```js
function createWallet() {
  let balance = 0;

  return {
    add(amount) { balance += amount; },
    getBalance() { return balance; },
  };
}
```

## Ловушка из легаси: var в цикле

```js
const actions = [];
for (var i = 0; i < 3; i++) {
  actions.push(() => i);
}
actions[0]();   // 3, а не 0
```

Переменная, объявленная через `var`, одна на всю функцию, а не своя на каждый шаг цикла. Все три стрелки помнят одну и ту же `i`, а к моменту вызова она уже равна 3.

С `let` у каждого шага цикла своя переменная, и всё работает ожидаемо. Это одна из главных причин, по которым `var` больше не пишут. В старом коде эта ошибка встречается постоянно — узнавай её в лицо.
