# Проект: список дел с сервером

В прошлом блоке список дел жил в `localStorage`. Теперь данные лежат на сервере, и каждое действие — это запрос, который занимает время и может не удаться. Логика почти та же, но появляется то, чего раньше не было: ожидание и ошибки.

Разметка и стили готовы, твоя часть — скрипт. API описано в прошлом уроке.

## Что должно работать

**Загрузка**

- Функция `loadTodos()` запрашивает список с сервера и рисует его. Она возвращает промис, который выполняется, когда список отрисован.
- Пока идёт запрос, в `#status` написано `Загрузка…`. После успеха `#status` пуст.
- Если дел нет, показан абзац `#empty`. Если есть — он скрыт.
- В конце скрипта вызывается `loadTodos()`.

**Список**

Каждое дело — элемент списка `#todos`:

```html
<li class="todo" data-id="5">
  <span class="text">Заказать зёрна</span>
  <button type="button" class="delete">×</button>
</li>
```

Текст вставляется как текст, а не как разметка.

**Добавление**

- Отправка формы `#new-todo` отправляет `POST` с текстом из поля `#todo-text`.
- Пустой текст и текст из одних пробелов запрос не отправляют.
- На время запроса кнопка формы отключена. После ответа — снова включена, при любом исходе.
- После успеха дело появляется в списке с `id`, который вернул сервер, а поле очищается.

**Удаление**

- Кнопка `.delete` отправляет `DELETE` для своего дела.
- Дело исчезает из списка **после** успешного ответа сервера, а не сразу по щелчку.

**Ошибки**

- Если любой запрос не удался — сервер ответил ошибкой или нет сети — в `#error` появляется текст `Не удалось выполнить запрос`, и элемент становится видимым.
- При ошибке список остаётся таким, каким был: неудачное добавление ничего не добавляет, неудачное удаление ничего не удаляет. При неудачном добавлении текст в поле сохраняется, чтобы человек не набирал его заново.
- Следующий успешный запрос скрывает `#error`.

## Как устроить код

Схема та же, что в прошлом проекте, только `load` и `save` теперь — запросы:

```js
let todos = [];                    // состояние — копия того, что на сервере

async function request(url, options) { … }   // fetch + проверка response.ok
function render() { … }                      // todos → страница
async function loadTodos() { … }
```

Полезно сделать одну функцию `request`, через которую идут все запросы: она проверяет `response.ok` и бросает ошибку. Тогда каждый обработчик — это `try` с запросом и изменением состояния и `catch` с показом ошибки.

Порядок в обработчике важен: **сначала запрос, потом изменение состояния**. Если поменять `todos` до ответа, при ошибке страница покажет то, чего на сервере нет.

## Порядок работы

1. План.
2. `request`, `render` и `loadTodos` — список с сервера появляется на странице.
3. Состояния: `Загрузка…`, `#empty`.
4. Добавление.
5. Удаление.
6. Ошибки. Проверить руками можно, временно дописав `?fail=1` к адресу запроса.
