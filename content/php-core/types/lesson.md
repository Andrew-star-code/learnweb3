# Типы и переменные

Ты уже умеешь программировать на JavaScript. PHP решает те же задачи теми же приёмами — меняется запись и несколько важных деталей. В этом блоке каждый урок построен на сравнении: что так же, что иначе.

Главное отличие — не в синтаксисе, а в том, **где и когда код выполняется**. JavaScript работает в браузере, пока открыта страница. PHP работает на сервере: получил запрос, выполнился сверху вниз, отдал ответ и завершился. Каждый запрос начинается с чистого листа.

## Первая программа

```php
<?php

declare(strict_types=1);

$name = 'Аня';
$age = 30;

echo "Привет, $name! Через год тебе будет " . ($age + 1) . ".\n";
```

Что здесь нового:

- Файл начинается с `<?php`. Закрывающий тег `?>` в файлах с одним кодом не пишут.
- Переменные начинаются с `$`. Объявлять их заранее не нужно: переменная появляется при первом присваивании. Слов `let` и `const` нет.
- Точка с запятой обязательна.
- Вывод — `echo`. Для отладки есть `var_dump($value)`: он показывает и значение, и тип.
- Строки склеивает **точка**, а не плюс. Плюс в PHP только складывает числа.

`declare(strict_types=1)` включает строгую проверку типов при вызове функций. Пиши эту строку первой в каждом файле — о ней ниже.

## Типы

| Тип | Примеры | Как в JavaScript |
|---|---|---|
| `int` | `42`, `-7` | В JS один тип `number` |
| `float` | `3.14`, `1.0` | |
| `string` | `'текст'`, `"текст"` | `string` |
| `bool` | `true`, `false` | `boolean` |
| `null` | `null` | `null`; отдельного `undefined` в PHP нет |
| `array` | `[1, 2]`, `['a' => 1]` | И массив, и объект-словарь сразу — следующий урок |
| объект | `new User()` | Экземпляр класса |

Целые и дробные числа — разные типы. `7 / 2` даёт `3.5`, а целочисленное деление — `intdiv(7, 2)`.

## Строки: два вида кавычек

```php
$name = 'Аня';

echo 'Привет, $name\n';     // Привет, $name\n — всё буквально
echo "Привет, $name\n";     // Привет, Аня и перевод строки
echo "Цена: {$item['price']} ₽";   // сложное выражение — в фигурных скобках
```

В одинарных кавычках ничего не подставляется. В двойных подставляются переменные и работают `\n`, `\t`. Правило: одинарные по умолчанию, двойные — когда нужна подстановка.

## Сравнение

Как и в JavaScript, есть нестрогое `==` и строгое `===`. И правило то же: **всегда `===`**.

```php
0 == 'a'        // false в PHP 8, но true в PHP 7!
'1' == '01'     // true
100 == '1e2'    // true
null == false   // true

0 === 'a'       // false — всегда
```

Первая строка — одно из изменений, которые молча поменяли поведение старого кода при переходе на PHP 8. Со строгим сравнением этой проблемы нет.

## Ложные значения

В условии ложными считаются: `false`, `0`, `0.0`, `''`, `null`, пустой массив `[]` — и строка `'0'`.

Два отличия от JavaScript, о которые спотыкаются:

- **Пустой массив ложен.** В JS `[]` истинен.
- **Строка `'0'` ложна.** Проверка `if ($input)` отбросит ввод «0».

Поэтому для проверки «значение задано» используют явные сравнения: `$value !== ''`, `$value !== null`, `count($items) > 0`.

## null и отсутствующие значения

```php
$city = $user['city'] ?? 'не указан';     // если ключа нет или там null
$count ??= 0;                             // присвоить, только если не задано
isset($user['city'])                      // есть и не null
```

Обращение к несуществующей переменной или ключу массива — это предупреждение, а не тихий `undefined`. Оператор `??` — основной способ безопасно прочитать то, чего может не быть.

## Преобразование типов

```php
(int) '42'          // 42
(int) '42 рубля'    // 42 — берётся число из начала строки
(int) 'много'       // 0
(float) '3.5'       // 3.5
(string) 42         // '42'
(bool) '0'          // false

is_numeric('42')    // true — проверить перед преобразованием
```

Всё, что приходит из формы или адресной строки, — строки. Прежде чем считать, проверь `is_numeric` и приведи тип.

## Константы

```php
const TAX_RATE = 0.2;

echo TAX_RATE;      // без знака $
```

## strict_types

Без `declare(strict_types=1)` PHP молча приводит аргументы к объявленному типу: функция, ожидающая `int`, примет строку `'5'`. Со строгим режимом такой вызов — ошибка `TypeError`. Строгий режим ловит опечатки и перепутанные аргументы сразу, а не через три экрана.

> **В PHP 7.** Всё из этого урока работает и в PHP 7.0, включая `??` и `declare(strict_types=1)`. Не работает только `??=` — он появился в 7.4. И помни про `0 == 'a'`: в PHP 7 это `true`.
>
> Под редактором есть выбор версии: кнопка «Запустить» выполнит код на PHP 8.3 или на 7.0. Версия 7.0 доступна, если платформа запущена через `docker compose`.
