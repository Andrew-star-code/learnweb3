# Проект: разбор журнала веб-сервера

Веб-сервер записывает каждый запрос строкой в файл журнала. Когда сайт тормозит или его кто-то перебирает, первым делом смотрят туда. Проект блока — набор функций и классов, который превращает такой журнал в отчёт.

Это прямой родственник проекта «Учёт расходов» из блока JavaScript: разбор текста, группировка, отчёт. Только на PHP и с классами.

## Формат

Каждая строка — один запрос:

```text
192.168.1.10 GET /catalog 200 512
192.168.1.10 GET /catalog/5 200 1024
10.0.0.7 POST /login 401 120
10.0.0.7 POST /login 401 120
192.168.1.22 GET /missing 404 80
10.0.0.7 POST /login 500 0
```

Пять полей через пробел: адрес клиента, метод, путь, код состояния, размер ответа в байтах.

## Требования

**1. Класс `LogEntry`** — одна запись журнала.

- Конструктор принимает `string $ip`, `string $method`, `string $path`, `int $status`, `int $bytes` и сохраняет их в публичные свойства только для чтения с теми же именами.
- Метод `isError(): bool` — истина, если код состояния 400 и выше.

**2. Класс `LogParseException`**, наследник `RuntimeException`.

**3. Функция `parseLine(string $line): LogEntry`**

- Разбирает строку в объект. Лишние пробелы по краям строки не мешают.
- `status` и `bytes` становятся целыми числами.
- Если полей не пять, бросает `LogParseException` с текстом `Неверный формат строки`.
- Если код состояния или размер — не целое неотрицательное число, бросает `LogParseException` с текстом `Неверное число`.

**4. Функция `parseLog(string $text): array`**

- Разбирает весь текст и возвращает список объектов `LogEntry`.
- Пустые строки пропускаются.
- Ошибка в строке превращается в `LogParseException` с номером строки: `Строка 3: Неверное число`. Исходное исключение сохраняется как предыдущее.

**5. Класс `LogReport`** — отчёт по списку записей.

- Конструктор принимает массив `LogEntry`.
- `total(): int` — число запросов.
- `errorRate(): float` — доля ошибочных запросов от 0 до 1; для пустого журнала `0.0`.
- `countByStatus(): array` — сколько запросов с каждым кодом: `[200 => 2, 401 => 2, …]`, ключи по возрастанию.
- `topIps(int $n): array` — `$n` самых активных адресов: `['10.0.0.7' => 3, '192.168.1.10' => 2]`, по убыванию числа запросов. При равенстве — по алфавиту адреса.
- `totalBytes(): int` — суммарный размер ответов.

## Как подойти

Пять частей, каждая следующая опирается на предыдущие.

1. План — первое задание.
2. `LogEntry` и `LogParseException` — это несколько строк.
3. `parseLine`. Написал — вызови на одной строке из примера и выведи результат через `var_dump`.
4. `parseLog`.
5. `LogReport` — по одному методу за раз.

Тесты идут в том же порядке, что и требования. Готового решения нет, подсказки есть.
