# Массивы

В JavaScript есть массив `[1, 2, 3]` и объект `{ name: 'Аня' }`. В PHP обе роли играет один тип — `array`. Это упорядоченный набор пар «ключ — значение», где ключом может быть число или строка.

## Список и словарь

```php
$drinks = ['Эспрессо', 'Капучино', 'Раф'];      // ключи 0, 1, 2 — как массив в JS

$user = [                                        // ключи-строки — как объект в JS
    'name' => 'Аня',
    'age' => 30,
];

echo $drinks[0];        // Эспрессо
echo $user['name'];     // Аня

$drinks[] = 'Латте';    // добавить в конец — вместо push
$user['email'] = 'a@b.c';
unset($user['age']);    // удалить ключ

count($drinks);         // длина — вместо .length
```

Доступ всегда через квадратные скобки. Точка в PHP занята склейкой строк.

Проверки:

```php
isset($user['email'])                 // ключ есть и значение не null
array_key_exists('email', $user)      // ключ есть, даже если там null
in_array('Раф', $drinks, true)        // есть ли такое значение; true — строгое сравнение
```

## Перебор

```php
foreach ($drinks as $drink) {
    echo $drink . "\n";
}

foreach ($user as $key => $value) {
    echo "$key: $value\n";
}
```

`foreach` — основной цикл в PHP. Он одинаково работает со списками и словарями.

## Массив копируется при присваивании

Главное отличие от JavaScript.

```php
$a = [1, 2, 3];
$b = $a;          // копия
$b[] = 4;

count($a);        // 3 — исходный массив не изменился
```

В JS `b = a` даёт вторую ссылку на тот же массив. В PHP массив ведёт себя как значение: при присваивании и при передаче в функцию получается независимая копия. Функция не может случайно испортить переданный ей массив.

Объекты в PHP, наоборот, передаются по ссылке — как в JS.

## Функции вместо методов

У массивов PHP нет методов. Вместо `items.map(fn)` пишут `array_map(fn, $items)`.

| Задача | JavaScript | PHP |
|---|---|---|
| Преобразование | `a.map(fn)` | `array_map($fn, $a)` |
| Отбор | `a.filter(fn)` | `array_filter($a, $fn)` |
| Накопление | `a.reduce(fn, init)` | `array_reduce($a, $fn, $init)` |
| Сумма | — | `array_sum($a)` |
| Ключи, значения | `Object.keys(o)` | `array_keys($a)`, `array_values($a)` |
| Столбец из таблицы | `a.map(x => x.name)` | `array_column($a, 'name')` |
| Склеить | `[...a, ...b]` | `array_merge($a, $b)` или `[...$a, ...$b]` |
| Срез | `a.slice(1, 3)` | `array_slice($a, 1, 2)` — третий аргумент это длина |
| Разворот | `a.toReversed()` | `array_reverse($a)` |
| Поиск значения | `a.indexOf(x)` | `array_search($x, $a, true)` |
| Уникальные | `[...new Set(a)]` | `array_unique($a)` |

Две ловушки:

- **Порядок аргументов разный.** У `array_map` функция идёт первой, у `array_filter` и `array_reduce` — второй. Это историческая непоследовательность, её приходится помнить.
- **`array_filter` сохраняет ключи.** После отбора из `[10, 20, 30]` может получиться `[0 => 10, 2 => 30]` — с «дыркой». Чтобы снова получить обычный список, оборачивай в `array_values(...)`.

```php
$prices = [100, 250, 40];

$doubled = array_map(fn($p) => $p * 2, $prices);                        // [200, 500, 80]
$big = array_values(array_filter($prices, fn($p) => $p >= 100));        // [100, 250]
$total = array_sum($prices);                                            // 390
```

`fn($p) => $p * 2` — стрелочная функция, как в JS. Подробнее — в следующем уроке.

## Сортировка

Функции сортировки **меняют сам массив** и возвращают `true`, а не отсортированную копию.

```php
$prices = [100, 25, 9];
sort($prices);                          // [9, 25, 100] — числа сортируются как числа

usort($users, fn($a, $b) => $a['age'] <=> $b['age']);    // по своему правилу
```

`<=>` возвращает `-1`, `0` или `1` — ровно то, что нужно функции сравнения. Вместо `a - b` из JavaScript.

| Функция | Что делает |
|---|---|
| `sort`, `rsort` | По значениям, ключи сбрасываются |
| `asort`, `arsort` | По значениям, ключи сохраняются — для словарей |
| `ksort` | По ключам |
| `usort` | По своей функции сравнения |

Благодаря копированию исходные данные легко сохранить: отсортируй копию.

## Массив как счётчик

Приём из урока про объекты в JS выглядит так же:

```php
$counts = [];
foreach ($words as $word) {
    $counts[$word] = ($counts[$word] ?? 0) + 1;
}
```

## Распаковка

```php
[$first, $second] = $drinks;
['name' => $name, 'age' => $age] = $user;
```

> **В PHP 7.** Стрелочных функций `fn` нет до версии 7.4 — в 7.0–7.3 пишут `function ($p) { return $p * 2; }`. Распаковка `[...]` работает с 7.1, до неё — `list($first, $second) = $drinks`. Оператор `...` внутри массива — с 7.4. Короткий синтаксис `[]` и оператор `<=>` есть и в 7.0. В очень старом коде встретишь `array(1, 2, 3)` — это то же, что `[1, 2, 3]`.
