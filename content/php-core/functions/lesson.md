# Функции

Функции в PHP устроены как в JavaScript, с двумя заметными отличиями: у параметров и результата указывают типы, а внешние переменные внутри функции не видны.

## Объявление и типы

```php
function withTax(float $price, float $rate = 0.2): float
{
    return $price * (1 + $rate);
}

withTax(100.0);        // 120.0
withTax(100.0, 0.1);   // 110.0
```

- Тип перед параметром, тип результата после двоеточия.
- Значение по умолчанию — как в JS.
- Функцию можно вызывать выше места, где она объявлена.

| Запись типа | Что означает |
|---|---|
| `int`, `float`, `string`, `bool`, `array` | Соответствующий тип |
| `?string` | Строка или `null` |
| `int\|string` | Одно из двух (PHP 8) |
| `mixed` | Что угодно (PHP 8) |
| `void` | Функция ничего не возвращает |
| `callable` | Функция |

Типы — не украшение. Со `strict_types` вызов с неверным типом сразу даёт `TypeError` с именем функции и номером аргумента. Это та проверка, которую в JavaScript приходилось писать руками.

Функция без `return` возвращает `null`.

## Область видимости: главное отличие

В JavaScript функция видит переменные, объявленные снаружи. В PHP — **нет**.

```php
$rate = 0.2;

function tax(float $amount): float
{
    return $amount * $rate;     // Warning: Undefined variable $rate
}
```

Внутри функции существуют только её параметры и то, что объявлено в ней самой. Всё нужное передаётся аргументами.

В старом коде ты встретишь `global $rate;` в начале функции — так внешнюю переменную «подключают» внутрь. Это рабочий, но плохой приём: функция начинает зависеть от того, что происходит где-то ещё. Узнавай его в легаси и не используй в новом коде.

## Анонимные функции и use

Функцию можно записать в переменную и передать как аргумент. Чтобы она увидела внешнюю переменную, её нужно явно перечислить в `use`:

```php
$limit = 100;

$expensive = array_filter($prices, function ($price) use ($limit) {
    return $price > $limit;
});
```

`use` копирует значение в момент создания функции. Это замыкание — как в JS, только список захваченных переменных пишется явно.

## Стрелочные функции

```php
$expensive = array_filter($prices, fn($price) => $price > $limit);
```

Стрелочная функция — одно выражение, результат возвращается сам. И она **видит внешние переменные без `use`**. Для коротких колбэков почти всегда пишут её.

## Именованные аргументы

```php
number_format(1234.5, 2, '.', ' ');
number_format(num: 1234.5, decimals: 2, thousands_separator: ' ');
```

Аргумент можно передать по имени параметра. Это удобно, когда параметров много или нужно задать последний, пропустив средние. Появились в PHP 8.

## Переменное число аргументов

```php
function sum(int ...$numbers): int
{
    return array_sum($numbers);
}

sum(1, 2, 3);          // 6
sum(...[4, 5]);        // распаковка массива в аргументы
```

## Передача по ссылке

Обычно функция получает копию значения. Амперсанд перед параметром меняет это: функция работает с переменной вызывающего кода.

```php
function addTax(array &$prices): void
{
    foreach ($prices as $key => $price) {
        $prices[$key] = $price * 1.2;
    }
}
```

Так устроены встроенные `sort` и `shuffle` — поэтому они меняют массив и ничего не возвращают. В своём коде передача по ссылке нужна редко: функция, которая возвращает новое значение, понятнее.

## Функция по имени

В PHP функцию можно передать строкой с её именем:

```php
array_map('trim', $lines);
array_map('strtoupper', $words);
```

В PHP 8.1 появилась более надёжная запись: `array_map(trim(...), $lines)`.

> **В PHP 7.** Типы `int`, `string`, `float`, `bool` в параметрах и тип результата есть с 7.0. `?string` и `void` — с 7.1. Стрелочные функции — с 7.4. Объединения `int|string`, `mixed` и именованные аргументы — только PHP 8. В версиях 7.0–7.3 колбэк пишется полностью: `function ($price) use ($limit) { return $price > $limit; }`.
