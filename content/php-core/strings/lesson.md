# Строки

Со строками в PHP работают функциями, а не методами: не `text.trim()`, а `trim($text)`. Набор функций богатый, но с двумя особенностями — непоследовательные имена и байты вместо символов.

## Строка — это байты

Главное, что нужно знать о строках PHP, особенно работая с русским текстом.

```php
strlen('кот');          // 6, а не 3
strtoupper('кот');      // 'кот' — не изменилось (в PHP 8)
substr('привет', 0, 3); // 'п' и половина буквы — испорченная строка
```

Обычные строковые функции считают **байты**. В кодировке UTF-8 латинская буква занимает один байт, русская — два. Пока текст английский, всё работает, а на кириллице ломается.

Для текста на любом языке есть функции с приставкой `mb_`:

| Задача | Только латиница | Любой текст |
|---|---|---|
| Длина | `strlen` | `mb_strlen` |
| Часть строки | `substr` | `mb_substr` |
| Регистр | `strtoupper`, `strtolower` | `mb_strtoupper`, `mb_strtolower` |
| Позиция подстроки | `strpos` | `mb_strpos` |
| Первая буква заглавная | `ucfirst` | своей функцией — см. задание |

Правило: **если в строке может оказаться не латиница — пиши `mb_`**. Имена, адреса, названия товаров — это всегда «может».

Функции, которым кодировка не важна, работают правильно без `mb_`: `trim`, `explode`, `implode`, `str_replace`, `str_contains`.

## Основные функции

```php
trim('  да ')                          // 'да'
str_replace('-', ' ', 'a-b-c')         // 'a b c' — заменяет все вхождения
str_contains('a@b.c', '@')             // true
str_starts_with('/admin/users', '/admin')
str_ends_with('photo.jpg', '.jpg')
str_pad('7', 2, '0', STR_PAD_LEFT)     // '07'
str_repeat('*', 3)                     // '***'
mb_substr('привет', 0, 3)              // 'при' — начало и длина, а не начало и конец
mb_substr('привет', -3)                // 'вет'
```

Порядок аргументов в старых функциях разный: в `str_replace` сначала что искать, потом где, а в `strpos` — наоборот. Помнить это не обязательно: редактор подсказывает, а именованные аргументы снимают вопрос.

### Ловушка strpos

```php
if (strpos($email, '@')) { … }               // ошибка!
if (strpos($email, '@') !== false) { … }     // правильно
```

`strpos` возвращает позицию или `false`. Позиция `0` — законный ответ «найдено в самом начале», но в условии ноль ложен. Сравнивать нужно строго с `false`. В PHP 8 для проверки «содержит ли» есть `str_contains`, и ловушки нет.

## Разобрать и собрать

```php
explode('-', '2024-03-15');            // ['2024', '03', '15'] — как split
implode('.', ['15', '03', '2024']);    // '15.03.2024' — как join

$title = implode(' ', array_map('trim', explode(',', $line)));
```

Ход тот же, что в JS: разбить → обработать функциями массивов → склеить.

Разбить на символы: `mb_str_split('кот')` → `['к', 'о', 'т']`.

## Форматирование

```php
sprintf('%s: %d шт. по %.2f ₽', 'Кофе', 3, 890.5);    // 'Кофе: 3 шт. по 890.50 ₽'
sprintf('%05d', 42);                                   // '00042'
number_format(1234567.891, 2, ',', ' ');               // '1 234 567,89'
```

`sprintf` подставляет значения в шаблон: `%s` — строка, `%d` — целое, `%.2f` — число с двумя знаками после точки. Он удобнее длинной склейки через точку.

## Регулярные выражения

```php
preg_match('/^\d{6}$/', $index)                        // 1, если совпало, 0 — если нет
preg_match('/(\d+) руб/', $text, $matches);            // найденное — в $matches
preg_replace('/\s+/', ' ', $text)                      // заменить
preg_split('/\s+/', $text)                             // разбить
```

Для кириллицы добавляй флаг `u`: `/[а-яё]+/iu`.

## Безопасный вывод

Любую строку, которая попадает в HTML, нужно экранировать:

```php
echo htmlspecialchars($comment);
```

Функция заменяет `<`, `>`, `&` и кавычки на безопасные коды. Это серверный аналог `textContent` и защита от XSS. Подробно — в блоках «PHP и веб» и «Безопасность», но привычку стоит заводить сразу.

> **В PHP 7.** `str_contains`, `str_starts_with` и `str_ends_with` появились в PHP 8. В PHP 7 вместо них `strpos($text, $part) !== false` и `strpos($text, $prefix) === 0`. `mb_str_split` — с 7.4. Функции `mb_*` требуют расширения `mbstring`: в старых установках его может не быть — тогда вызов закончится ошибкой «undefined function».
