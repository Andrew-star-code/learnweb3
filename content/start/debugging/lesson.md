# Отладка: когда код работает не так

Отладка — это не «смотреть на код, пока не увидишь ошибку». Это короткий повторяющийся цикл, похожий на эксперимент:

1. **Ожидание.** Что должно получиться? Конкретно: «для `'привет  мир'` функция должна вернуть 2».
2. **Факт.** Что получилось на самом деле? «Вернула 3».
3. **Гипотеза.** Где ожидание и факт могли разойтись? «Наверное, после `split` в массиве не два элемента».
4. **Проверка.** Выведи промежуточное значение и посмотри.
5. Гипотеза подтвердилась — исправляй. Нет — выдвигай следующую.

## console.log как рентген

Самый простой инструмент — вывести то, что находится в переменной, прямо посреди работы программы.

```js
function countWords(text) {
  const words = text.split(' ');
  console.log('words:', words);      // что на самом деле в массиве?
  return words.length;
}
```

Несколько правил, которые делают вывод полезным:

- **Подписывай** значение: `console.log('total:', total)`, а не просто `console.log(total)`.
- **Выводи в цикле** — так видно, на каком шаге значение стало неправильным.
- **Проверяй тип**, если значение выглядит нормально, а ведёт себя странно: `console.log(typeof price)`. Строка `'10'` и число `10` при выводе выглядят одинаково.

## Где искать: деление пополам

Если непонятно, в какой части функции ошибка, поставь вывод **посередине**. Значение там правильное — значит, ошибка во второй половине. Неправильное — в первой. Повтори с нужной половиной. За три-четыре вывода находится место в функции любой длины.

## Три ошибки, которые стоит узнавать в лицо

**Переменная обнуляется в цикле.** Накопитель объявлен внутри цикла и на каждом шаге создаётся заново:

```js
for (const n of numbers) {
  let total = 0;      // должно стоять до цикла
  total += n;
}
```

**Строка вместо числа.** Всё, что приходит из полей формы, из адресной строки и из текстовых файлов, — строки. Плюс для строк означает склейку: `'10' + 20` даёт `'1020'`. Лечится преобразованием: `Number('10')`.

**Неожиданные данные.** Код верен для «хорошего» входа, но ломается на пустой строке, пустом массиве, двойных пробелах. Всегда проверяй хотя бы один «плохой» пример.

## Объясни утёнку

Если застрял — объясни свой код вслух, строчка за строчкой, хоть резиновой уточке на столе. Проговаривая, что *должна* делать каждая строка, ты заметишь ту, которая делает другое. Метод звучит несерьёзно, но им пользуются повсеместно.

> Кроме `console.log` есть настоящий отладчик: он останавливает программу на нужной строке и показывает все переменные. Он встроен в браузер. Попробуй его, когда дойдём до блока «JavaScript в браузере», а описание — по ссылке ниже.
