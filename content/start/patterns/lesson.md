# Типовые приёмы: из чего собираются решения

Когда план готов, каждый его шаг нужно превратить в код. Здесь выручает то, что большинство шагов в повседневных задачах — это один из нескольких **типовых приёмов**. Опытный разработчик не придумывает цикл заново: он узнаёт в шаге знакомый приём и пишет его по памяти.

Ниже четыре приёма, которые покрывают большую часть задач с наборами данных. Все они построены на одном и том же каркасе: **переменная до цикла → цикл → результат после цикла**.

## 1. Накопление

Нужно получить из набора одно значение: сумму, количество, склеенную строку.

```js
let total = 0;                // начальное значение
for (const price of prices) {
  total += price;             // добавляем к накопленному
}
// total — результат
```

## 2. Поиск лучшего

Нужно найти самое большое, самое дешёвое, самое длинное.

```js
let max = numbers[0];         // лучшим пока считаем первый элемент
for (const n of numbers) {
  if (n > max) {
    max = n;                  // нашли лучше — запомнили
  }
}
```

Начальное значение — **первый элемент набора**, а не ноль. Если взять ноль, то для набора из одних отрицательных чисел ответом окажется ноль, которого в наборе вообще нет.

## 3. Отбор

Нужно оставить только подходящие элементы.

```js
const result = [];            // пустой массив для подходящих
for (const user of users) {
  if (user.age >= 18) {
    result.push(user);        // подходит — кладём
  }
}
```

## 4. Преобразование

Нужно получить новый набор той же длины, где каждый элемент изменён.

```js
const result = [];
for (const name of names) {
  result.push(name.toUpperCase());   // кладём изменённый элемент
}
```

## Как этим пользоваться

Смотри на шаг плана и спрашивай себя: что должно получиться?

| Что нужно получить | Приём |
|---|---|
| Одно число или строку из всего набора | Накопление |
| Один элемент — «самый-самый» | Поиск лучшего |
| Часть элементов | Отбор |
| Столько же элементов, но изменённых | Преобразование |

Приёмы комбинируются. «Сумма заказов дороже 1000» — это отбор, а затем накопление. Их можно записать двумя циклами подряд или одним циклом с `if` внутри.

> У массивов в JavaScript есть готовые методы для этих приёмов: `reduce`, `filter`, `map`. Мы дойдём до них в блоке «Ядро JavaScript». Сначала полезно набить руку на циклах: методы делают внутри ровно то же самое.
