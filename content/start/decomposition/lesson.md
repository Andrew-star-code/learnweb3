# Декомпозиция: от задачи к шагам

Ступор перед пустым файлом возникает не от незнания синтаксиса. Он возникает, когда пытаешься придумать всё решение целиком и сразу записать его кодом. Так не делают даже опытные разработчики: они сначала дробят задачу на шаги, каждый из которых уже понятно, как написать.

Этот навык называется **декомпозицией**, и он тренируется так же, как любой другой.

## Пять шагов

1. **Перескажи задачу своими словами** и запиши пример: что на входе, что должно получиться на выходе.
2. **Реши пример руками**, без кода. Следи за тем, что именно ты делаешь, — это и есть будущий алгоритм.
3. **Запиши свои действия по шагам** обычным языком.
4. **Перенеси шаги в файл как комментарии.**
5. **Под каждым комментарием напиши код** и запускай после каждого шага, а не в самом конце.

Если какой-то шаг не получается сразу записать кодом — значит, он слишком крупный. Разбей его ещё раз тем же способом.

## Пример

Задача: *посчитать, сколько в тексте слов длиннее трёх букв.*

**Шаг 1. Пример.** На входе `'я иду домой через парк'`, на выходе `3` (слова «домой», «через», «парк»).

**Шаг 2. Руками.** Я смотрю на слова по одному. У каждого считаю буквы. Если букв больше трёх — загибаю палец. В конце смотрю, сколько пальцев загнуто.

**Шаг 3. Шаги словами.**

1. Разбить текст на слова.
2. Завести счётчик, равный нулю.
3. Пройти по всем словам.
4. Если слово длиннее трёх букв — увеличить счётчик.
5. Вернуть счётчик.

**Шаги 4 и 5. Комментарии, а под ними код.**

```js
function countLongWords(text) {
  // 1. Разбить текст на слова
  const words = text.split(' ');

  // 2. Завести счётчик
  let count = 0;

  // 3. Пройти по всем словам
  for (const word of words) {
    // 4. Если слово длиннее трёх букв — увеличить счётчик
    if (word.length > 3) {
      count++;
    }
  }

  // 5. Вернуть счётчик
  return count;
}
```

Обрати внимание: ни один из пяти шагов по отдельности не сложный. Сложной казалась только задача целиком.

> **Как устроены задания.** В каждом уроке задания идут лестницей: сначала дописать пропуск, потом починить, потом написать по тестам, потом с нуля. В заданиях с меткой «План» кода нет вообще: ты пишешь шаги словами и сравниваешь с разбором. Не пропускай их — именно они лечат ступор.
